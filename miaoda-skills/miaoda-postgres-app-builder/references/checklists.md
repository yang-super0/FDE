# 各阶段检查清单汇总

## 阶段1：需求分析

- [ ] 用户角色已明确
- [ ] 核心业务流程已梳理
- [ ] **页面清单已输出**（每页类型/数据来源/关键交互/访问角色）
- [ ] **数据表清单已输出**（每表实体/核心字段/被哪些页面用到/数据量预估）
- [ ] **实体关系图（ER 图）已画出**（1:1 / 1:N / N:N 关系清晰）
- [ ] **AI 功能清单已输出**（输入/候选数据来源/输出结构/同步异步），如有
- [ ] 三张清单 + ER 图与原始需求逐条对应、无遗漏
- [ ] 清单已经用户确认后才开工
- [ ] 高风险点已识别（大数据量表/高并发写入/复杂统计/批量操作）

## 阶段2：数据库设计

- [ ] 所有表已创建（一表一实体）
- [ ] 命名规范：表名小写下划线复数、字段名小写下划线
- [ ] 主键统一用 `id`（BIGSERIAL）
- [ ] 外键命名为 `xxx_id`，已建立外键约束
- [ ] **金额字段用 `NUMERIC(12,2)`**，不是 FLOAT
- [ ] **时间字段用 `TIMESTAMPTZ`**，不是 TIMESTAMP
- [ ] 所有表都有 `created_at` 和 `updated_at`
- [ ] 需要软删除的表有 `deleted_at` 字段
- [ ] 枚举字段用 VARCHAR + CHECK 约束
- [ ] NOT NULL / UNIQUE / CHECK 约束已添加
- [ ] **所有 WHERE / JOIN / ORDER BY 字段已建索引**
- [ ] 复合索引字段顺序正确（区分度高的在前）
- [ ] updated_at 自动更新触发器已配置
- [ ] 测试数据已录入（每表 20~50 条，含边界值）
- [ ] **关键查询已用 `EXPLAIN ANALYZE` 验证走索引**
- [ ] 表结构已经和用户确认

## 阶段3：妙搭应用创建与配置

- [ ] 妙搭应用已创建，选择的是「完整应用」（不是仅前端页面）
- [ ] 内置 PostgreSQL 可用，能执行 SQL（`SELECT version()` 验证）
- [ ] 环境变量已配置（AI Key、第三方服务等）
- [ ] 数据库分支策略已建立（main / dev / feature）
- [ ] 所有表已在数据库中创建，字段/约束/索引与设计一致
- [ ] 测试数据已录入
- [ ] 关键查询已验证走索引
- [ ] 用户认证和权限已配置（如需要）

## 阶段4：开发实现（分模块小闭环）

### 模块切片与节奏

- [ ] 已完成模块切片与开发排序（数据层→主表→其余表→搜索→统计→AI→收尾）
- [ ] **一次只开发一个模块，未一次性生成全部模块**
- [ ] **每个模块开发后立即在预览自测通过，才进入下一模块**
- [ ] 开发下一模块时已约束"不破坏已测通过模块"，并做回归

### 数据层

- [ ] 数据库连接和 ORM/数据层已配置
- [ ] **所有列表接口支持分页**（page + page_size）
- [ ] **关联查询用 JOIN，无 N+1**
- [ ] **所有用户输入用参数化查询，无 SQL 拼接**
- [ ] **多表写入使用事务**
- [ ] 软删除查询都加了 `WHERE deleted_at IS NULL`
- [ ] 统计查询用 SQL 聚合（GROUP BY / SUM / COUNT），未拉全量到内存
- [ ] 接口返回格式统一（标准 RESTful）

### 页面与交互

- [ ] 列表页：表格 + 筛选（含"全部"分支）+ 分页 + 搜索 + 新增 + 行操作
- [ ] 表单页：字段验证 + 关联选择器 + 提交 + 取消返回
- [ ] 详情页：主表信息 + 关联数据 + 操作按钮
- [ ] 仪表盘：指标卡 + 趋势图 + 分布图 + 排行榜（数据来自 SQL 聚合）
- [ ] 表单验证已添加（必填、格式、范围）

### AI 组件（如有）

- [ ] AI 入参空值已兜底，无空字符串传入
- [ ] 候选数据从数据库查（用 SQL），规则筛选排序
- [ ] 提示词已写"禁止空返回+补足条数+不得杜撰"
- [ ] AI 返回空/异常时前端有规则结果兜底，无空态白屏

### 性能

- [ ] 关键查询已用 `EXPLAIN ANALYZE` 验证走索引
- [ ] 列表查询响应 < 300ms
- [ ] 无全表拉取、无 N+1、无内存统计
