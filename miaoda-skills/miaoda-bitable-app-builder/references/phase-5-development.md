# 阶段5：开发实现（分模块小闭环）

## 目标
用妙搭 AI **按模块逐个**生成应用，每个模块即开即测，完成字段适配和数据回填。
**禁止一条指令让 AI 一次性做完所有模块**——问题会堆积、互相影响、难以定位（坑18）。

## 5.1 模块切片与开发排序
先把应用切成"用户可独立感知、能独立跑通"的模块（一块自带数据查询+页面+交互），再按依赖排序：

1. **数据连接层 / 字段适配**（地基，先打通取数）
2. 主表的列表页 + 详情页
3. 其余各表的列表页 + 详情页
4. 全局搜索 / 筛选
5. AI 推荐类能力
6. AI 生成类能力（方案/报告/话术）
7. 门户首页、聚合统计、收尾交互

一次只推进一个模块；强相关的两小块可合并，跨层/跨页面的不合并。

## 5.2 单模块"开发→自测→再开发"小闭环
对每个模块重复以下循环，全部通过后才进入下一模块：
1. 用【模板A】下发本模块开发指令（明确边界，先别发布）
2. AI 出方案后点"按方案执行"，完成本模块开发
3. 用【模板B】让 AI 只对本模块做自测，并在预览环境亲自验证正常路径+边界+数据来源
4. 有问题只修本模块，直到通过
5. 用【模板C】带回归约束开发下一模块

> 妙搭每次出方案都需要手动点"按方案执行"，下发指令后要持续跟进，不能发完就不管。

### 模板 A：单模块开发指令（限定边界）
```
【本次范围】只开发「模块名，如：资料分类库的列表+详情」，不要改动其他模块的任何文件。
【数据源】仅使用「表名 / 查询插件」；字段以线上真实定义为准：
  - 字段名（类型/单选枚举）：……（用阶段2回读的结果）
【要实现】
  1. …（每条都可验证）
  2. …
【本次不做】不做搜索、不做 AI、不重构已完成模块。
【完成后先别发布】
  - 列出本次改动的文件；
  - 在预览自测：正常路径、边界（全部/空值/无结果）、每条数据来自哪张表；
  - 自测通过后报告结果，等我确认再进入下一模块。
```

### 模板 B：模块自测指令（只验证、不加功能）
```
只验证「模块名」，不要新增功能：
1) 列出本模块数据链路：表 → 查询插件 → 页面；
2) 正常用例 + 边界用例（全部/空值/无匹配）各跑一遍；
3) 抓接口确认：入参字段/候选完整，出参非空；
4) 报告通过/失败；失败只修这个模块，不要动其他模块。
```

### 模板 C：下一模块的回归保护指令
```
继续开发「下一模块名」，范围与数据源如下：……
硬约束：不得修改或破坏已测通过的「模块A、模块B」。
完成后除自测新模块外，回归确认模块A、模块B仍正常；先别发布，等我确认。
```

## 5.3 必须实现的适配层

### 关联字段标题回填（必做）
原生 search API 返回的关联字段只有 `link_record_ids`，没有标题。
实现批量回填：
1. 查询主表列表 → 收集关联记录ID
2. 批量查询关联表 → 建立 ID→标题 映射
3. 回填到主表数据
- 复杂场景需两跳回填：收款→订单→客户名称

### 人员字段处理
- 有通讯录权限：走原生通道写 `[{"id": "ou_xxx"}]`（对象数组，ID 类型随接口 `user_id_type`，默认 open_id）
- 无权限：在表单层禁用人员字段并提示「需管理员开通通讯录权限后启用」，或改用文本字段兜底（不得降级插件通道——发布环境写操作必失败，坑1/坑4）
- 读取时提取 `name` 和 `id`

### 附件上传 / 下载
1. 前端选择文件 → 调用上传接口 → 获取 file_token
2. 写入附件字段：`[{file_token: "xxx"}]`
3. 读取时返回 `[{file_token, name, type, size, url, tmp_url}]`——`url` 需鉴权不可直用，`tmp_url` 是临时链接接口地址
4. **下载/预览：后端以 file_token 现调 `batch_get_tmp_download_url` 换取 24 小时有效的 `tmp_download_url` 给前端（一次最多 5 个 file_token，高级权限多维表格带 extra 参数）；每次展示现取，禁止缓存/落库/当永久地址；详情正文必须取真实文本，不做只能看不能用的按钮**（坑16）

## 5.4 AI 能力开发（单独成模块，严格四层）
AI 推荐/生成放在页面模块之后单独开发，严格遵循 `ai-component-patterns.md`：
1. 入参空值兜底（禁传空字符串）
2. 规则打底：候选合并所有相关表（对照数据血缘表，防漏表）、确定性加权排序、匹配回退
3. 提示词约束：禁止空返回、补足条数、不得杜撰候选、固定公司主体防幻觉
4. 结果校验 + 前端规则兜底（AI 空返回时用规则结果，绝不空态/白屏）
多表候选合并与血缘核对见 `data-lineage.md`。

## 5.5 页面开发标准
| 页面类型 | 必须包含 |
|---|---|
| 列表页 | 表格+筛选（含"全部"分支）+分页+新增按钮+行操作（编辑/删除） |
| 表单页 | 字段验证+关联选择器+提交按钮 |
| 详情页 | 真实信息展示+关联数据+可真实下载/跳转的操作按钮 |
| 仪表盘 | 指标卡+趋势图+分布图+排行榜 |

## 5.6 接口规范
标准RESTful：
- `GET /api/xxx` 列表
- `GET /api/xxx/:id` 详情
- `POST /api/xxx` 新增（返回201）
- `PUT /api/xxx/:id` 编辑
- `DELETE /api/xxx/:id` 删除
