# 阶段6：测试验证（全量 + 跨模块联调）

## 目标
在阶段5各模块自测的基础上，做全量回归、边界值扫描、跨模块一致性验证，并确保预览和发布环境都正常。
**注意：模块自测在阶段5已做；本阶段重点是"模块拼起来之后"的问题，且编译通过、AI 自称"自查通过"都不能替代实测（坑17）。**

## 6.1 预览环境功能测试
在妙搭编辑器预览中逐项验证：
- [ ] 各模块列表数据正常显示
- [ ] 新增操作成功（返回201）
- [ ] 编辑操作成功
- [ ] 删除操作成功
- [ ] 关联字段下拉选择正常
- [ ] 筛选/分页正常
- [ ] 仪表盘数据正确
- [ ] 无控制台报错

## 6.2 边界值测试（最易漏，必测）
只测正常路径一定会漏问题，以下分支逐一验证：
- [ ] 筛选/分类选"**全部**"时数据正常展示（默认分支最容易漏写导致空白）
- [ ] 必填留空：前端拦截并提示，不发请求
- [ ] 选填留空：有空值兜底，不报错（AI 入参不传空字符串）
- [ ] 输入无匹配/不存在的分类：走"其他/通用"回退，有结果、不白屏
- [ ] AI 返回空或超时：前端用规则结果兜底，无空态
- [ ] 下载按钮真实可下载、详情页能看到真实正文（不是 UI 壳子，坑16）

## 6.3 跨模块一致性
- [ ] 页面间跳转正常，模块拼起来无相互破坏（回归已测模块）
- [ ] 同一数据在不同页面展示口径一致
- [ ] 全局搜索候选覆盖所有应检索的表，每类内容都能搜到
- [ ] AI 推荐/生成的候选覆盖所有相关表（对照数据血缘表，防漏表）

## 6.4 接口级核对（不只看页面）
对关键列表、搜索、AI 接口，主动抓请求入参与返回：
- [ ] 入参字段/候选数据完整，无漏表、无空字符串
- [ ] 出参非空、结构符合预期（AI 重点查是否返回空字符串）
- [ ] 单选/关联字段返回值能被正确解析显示
> 只看 UI 容易被"恰好有数据"骗过；很多空返回、漏表问题只有抓接口才能发现。

## 6.5 发布环境测试（重点，在线上正式地址）
发布后在 feishuapp.com 正式地址测试（不用编辑器预览地址替代）：
- [ ] 页面能正常打开
- [ ] 列表有数据（不是空白）
- [ ] **新增操作返回201，不是500**（最关键）
- [ ] 编辑操作正常
- [ ] 删除操作正常
- [ ] 关联字段标题显示正常（不是空白）
- [ ] 人员字段显示和写入正常
- [ ] 附件下载/上传正常（如有）
- [ ] 关键搜索/AI 能力：正常输入 + 边界输入各一次

## 6.6 问题排查路径
遇到问题按此顺序排查：
1. 看妙搭「接口日志」红色报错，并抓问题接口的入参/出参
2. AI 类问题先查：候选是否漏表、入参是否有空串、出参是否为空（见 `ai-component-patterns.md`）
3. 复制报错信息给AI分析
4. 检查 `.env` 凭证是否正确
5. 检查飞书应用权限是否审批通过
6. 回读多维表格真实字段名/类型是否与代码一致（警惕单选误当文本）
7. 对照数据血缘表确认链路是否连通（见 `data-lineage.md`）

详细常见问题见 `pitfalls.md`。

## 完成标准
- [ ] 功能、边界值、跨模块一致性全部通过
- [ ] 关键接口已抓包核对入参完整、出参非空
- [ ] 预览环境所有功能通过
- [ ] 发布环境所有功能通过
- [ ] 写操作（新增/编辑/删除）在发布环境正常
- [ ] 无未解决的报错；未仅凭编译通过或 AI 自查判定完成
