## 阶段5：开发实现（分模块小闭环）
### 模块切片与节奏
- [ ] 已完成模块切片与开发排序（数据层→主表→其余表→搜索→AI→收尾）
- [ ] **一次只开发一个模块，未一次性生成全部模块**
- [ ] **每个模块开发后立即在预览自测通过，才进入下一模块**
- [ ] **开发下一模块时已约束"不破坏已测通过模块"，并做回归**

### 页面与数据
- [ ] 本模块列表页/表单页/详情页已生成
- [ ] 关联字段标题回填已实现
- [ ] 人员字段处理逻辑已实现（有权限走原生通道；无权限表单禁用/文本兜底，禁止降级插件通道）
- [ ] 附件上传流程已实现（如有）
- [ ] **下载/预览接现取临时下载链接（24小时时效、勿缓存），详情展示真实正文（非 UI 壳子）**
- [ ] 表单验证已添加
- [ ] **跨表写联动已实现幂等（先查后写）与失败回滚**
- [ ] 接口返回格式统一
- [ ] **本模块用到的每张表都已实测取到数（对照血缘表）**

### AI 组件（如有，对照 ai-component-patterns.md 四层）
- [ ] AI 入参空值已兜底，无空字符串传入
- [ ] 候选已合并所有相关数据表（无漏表）
- [ ] 规则筛选/排序在不调 AI 时也能产出稳定结果
- [ ] 匹配不到时有显式回退，不返回空集合
- [ ] 提示词已写"禁止空返回+补足条数+不得杜撰候选+固定主体"
- [ ] AI 返回空/异常时前端有规则结果兜底，无空态白屏
- [ ] 公司名等固定事实来自配置，关键生成事实标注需核实
