# 典型场景分析模板

> 本文件为 Skill 触发后按需加载的参考资料，提供常见困扰场景的阿德勒式分析框架。使用时根据用户具体情况选择对应场景，结合 core-concepts.md 中的概念进行深度引导。

---

## 场景一：职场人际关系（上司/同事/下属）

### 典型表现
- "我的上司总是针对我，不认可我的工作"
- "同事都比我优秀，我感到很自卑"
- "我不敢在会议上发言，怕被笑话"
- "因为上司的原因，我无法好好工作"

### 核心概念映射
- 课题分离：上司如何评价你是上司的课题，你如何工作是你的课题
- 目的论：你是否通过"讨厌的上司"来为"不想工作"找借口
- 横向关系：上司和你虽然职责不同，但在人格上是平等的
- 人生谎言："因为有那样一个上司，所以无法好好工作"——这是原因论式的人生谎言

### 分析步骤
1. **课题分离**：问用户——"上司不认可你，这是谁的课题？你如何做好工作，这是谁的课题？"
2. **目的论追问**："如果没有这个'讨厌的上司'，你会采取什么不同的行动？你是否通过这个上司来为'不想面对工作中的挑战'找借口？"
3. **纵向→横向**："你是把上司看作'上级'（纵向关系），还是看作'虽然职责不同但平等的伙伴'（横向关系）？"
4. **他者贡献**："你在工作中能否感受到'我对团队/他人有用'？这种贡献感是否需要上司的认可才能成立？"

### 行动建议
- 把"获得上司认可"的目标替换为"对团队做出贡献"
- 面对不合理要求时，基于横向关系正面表达自己的主张（不是傲慢，是坚持应有的主张）
- 不把上司的情绪当作自己的课题——上司发脾气是上司的课题，你如何应对是你的课题
- 如果关系实在无法调和，"剪断关系也是自己的课题"

## 场景二：亲密关系（恋爱/婚姻）

### 典型表现
- "我害怕被拒绝，所以不敢表白"
- "伴侣不理解我，我感到很孤独"
- "我总是怀疑对方不忠"
- "分手了，我走不出来"
- "我为TA付出了这么多，TA却不珍惜"

### 核心概念映射
- 课题分离：你如何爱对方是你的课题，对方如何回应是对方的课题
- 他者信赖：无条件信赖是建立深厚关系的基础，被背叛是对方的课题
- 目的论：你是否通过"害怕被拒绝"来逃避建立关系的风险
- 横向关系：真正的爱是平等的横向关系，不是支配与被支配
- 人生谎言："因为TA不珍惜我，所以我不幸"——把责任转嫁给对方

### 分析步骤
1. **课题分离**："你喜欢/爱对方，这是谁的课题？对方是否接受/回应，这是谁的课题？"
2. **目的论**："你通过'害怕被拒绝'达到了什么目的？是否避免了'即使表白也可能被拒绝'的自我否定？"
3. **信赖 vs 怀疑**："你是在选择'信赖'还是'怀疑'？如果把关系建立在怀疑之上，能找到对方不忠的'证据'吗？（答案是：总能找到）"
4. **横向关系**："你们的关系是平等的横向关系，还是一方支配另一方的纵向关系？你是否在通过'付出'来获得'我更有价值'的优越感？"

### 行动建议
- 区分"我爱你"（我的课题）和"你要爱我"（干涉对方课题）
- 阿德勒说："如果对方过得幸福，那就能够真诚地去祝福，这就是爱。"
- 被背叛时悲伤就悲伤，但要认识到：决定背不背叛的不是你，那是他人的课题
- 关系破裂不是失败，"承认错误、赔礼道歉、退出权力之争，这些都不是失败"
- 不要用"行为标准"衡量爱的价值，存在本身就有价值

## 场景三：家庭关系（父母/亲子/原生家庭）

### 典型表现
- "父母总是干涉我的人生选择"
- "我从小被父母否定，所以现在很自卑"
- "孩子不听话，我很焦虑"
- "我无法原谅父母过去对我的伤害"
- "我为孩子付出了一切，TA却不领情"

### 核心概念映射
- 课题分离：孩子的学习/人生是孩子的课题，父母不能干涉
- 目的论：你是否通过"父母的伤害"来为"现在的不努力"找借口
- 横向关系：亲子关系也应该是"虽然不同但是平等"的横向关系
- 鼓励 vs 表扬：表扬是纵向关系（有能力者评价没能力者），鼓励是基于横向关系的感谢
- 存在标准：不要用"行为标准"（考了多少分、做了什么）来衡量孩子的价值

### 分析步骤
1. **课题分离（子女视角）**："父母如何看待你的选择，这是谁的课题？你如何过自己的人生，这是谁的课题？"
2. **目的论（子女视角）**："你通过'父母过去的伤害'达到了什么目的？是否可以把现在的不幸归咎于父母，从而避免'自己做出改变'的责任？"
3. **课题分离（父母视角）**："孩子的学习/人生是谁的课题？你是在'援助'还是'干涉'？"
4. **横向关系（父母视角）**："你是在'表扬'孩子（纵向评价），还是在'鼓励'孩子（横向的感谢/喜悦）？你是用'行为标准'还是'存在标准'看待孩子？"

### 行动建议
- 对父母：把马带到水边，但不强迫其喝水。在孩子需要时随时准备给予帮助，但绝不妄加干涉
- 对子女：即使父母干涉，也要认识到"如何过自己的人生"是自己的课题。父母伤心是父母的课题，你无法也不必为别人的情绪负责
- 亲子沟通中，用"谢谢""帮了大忙了"代替"你真棒""你真聪明"
- 对闭居在家的孩子：首先断定"这是孩子的课题"，不妄加干涉；同时告诉孩子"在他困惑的时候我随时准备给予援助"
- 修复与父母的关系："人际关系之卡握在你自己手里"，你改变不是为了改变父母，但你的改变可能会带来关系的变化

## 场景四：自我否定与自卑感

### 典型表现
- "我一无是处，什么都做不好"
- "我长得不好看/学历低/家境差，所以很自卑"
- "我总是拿自己和别人比较，然后感到沮丧"
- "我讨厌自己"

### 核心概念映射
- 自卑感是主观臆造：自卑不是客观事实，是主观解释
- 自卑情结 vs 自卑感：自卑感是正常的成长动力，自卑情结是把自卑感当借口
- 目的论：你通过"讨厌自己"达到了什么目的？——避免在人际关系中受伤
- 自我接纳：接受60分的自己，然后思考如何接近100分
- 存在标准：不要用"行为标准"衡量自己的价值

### 分析步骤
1. **主观 vs 客观**："你说的'缺点'是客观事实，还是你主观赋予的解释？比如身高矮，客观上只是一个数字，'矮=不好'是主观解释。"
2. **目的论**："你通过'讨厌自己'达到了什么目的？是否可以避免'在人际关系中受伤'？——因为有这样的缺点才会遭人拒绝，只要没有这个缺点也会很讨人喜欢。"
3. **自卑感 vs 自卑情结**："你的自卑感是推动你进步的动力（'因为学历低所以要更努力'），还是你逃避的借口（'因为学历低所以无法成功'）？"
4. **比较对象**："你是在和'理想的自己'比较，还是在和'他人'比较？"

### 行动建议
- 区分"自我肯定"（明明做不到还说"我能行"）和"自我接纳"（接受做不到的自己，然后努力）
- 用"肯定性的达观"：分清"能改变的"和"不能改变的"，把精力放在能改变的部分
- 引用尼布尔的祈祷文："上帝，请赐予我平静，去接受我无法改变的；给予我勇气，去改变我能改变的；赐我智慧，分辨这两者的区别。"
- 从"行为标准"转向"存在标准"：你不是因为"做了什么"才有价值，而是"存在本身"就有价值
- 阿德勒说："重要的不是被给予了什么，而是如何去利用被给予的东西。"

## 场景五：讨好型人格/害怕被讨厌

### 典型表现
- "我总是忍不住讨好别人，不敢拒绝"
- "我害怕别人讨厌我，所以总是委屈自己"
- "我希望所有人都喜欢我"
- "我太在意别人的眼光，活得很累"

### 核心概念映射
- 认可欲求：寻求认可是以自我为中心的表现
- 课题分离：别人是否喜欢你是别人的课题
- 被讨厌的勇气：自由就是被别人讨厌
- 八面玲珑是不自由：想要讨好所有人的生活方式是极其不自由的
- 他者贡献：真正的价值感来自贡献感，不是来自他人的认可

### 分析步骤
1. **课题分离**："别人是否喜欢你/认可你，这是谁的课题？你如何生活，这是谁的课题？"
2. **目的论**："你通过'讨好所有人'达到了什么目的？是否避免了'被讨厌'的可能性？但代价是什么？——失去了自由，活在别人的人生中。"
3. **以自我为中心**："你有没有意识到，过度在意'别人怎么看我'本质上是只关心'我'的表现？这是另一种形式的以自我为中心。"
4. **二选一**："在'被所有人喜欢的人生'和'有人讨厌自己的人生'之间，你选哪个？"

### 行动建议
- 阿德勒的回答："如果在我面前有'被所有人喜欢的人生'和'有人讨厌自己的人生'这两个选择让我选的话，我一定会毫不犹豫地选择后者。比起别人如何看自己，我更关心自己过得如何。"
- 认识到："不想被人讨厌"是你的课题，但"是否讨厌我"是别人的课题
- 即使有人不喜欢你，那也不是你的课题。"应该喜欢我"或者"我已经这么努力了还不喜欢我也太奇怪了"之类的想法也是一种干涉对方课题的回报式思维
- 把"获得所有人的认可"替换为"对他人做出贡献"——贡献感不需要他人的认可
- 从"对自己的执著"转向"对他人的关心"

## 场景六：过去创伤/心结

### 典型表现
- "我童年的创伤影响了我的一生"
- "我无法原谅过去伤害过我的人"
- "因为过去的经历，我现在无法信任别人"
- "我总是想起过去的失败，无法释怀"

### 核心概念映射
- 心理创伤并不存在：决定我们的不是过去的经历，而是我们赋予经历的意义
- 目的论：你通过"过去的创伤"达到了什么目的？
- 人生谎言：把现在的不幸归咎于过去，是逃避责任的人生谎言
- 活在当下：过去不存在，未来也不存在，只有此时此刻
- 课题分离：过去的事情已经无法改变，如何看待过去是你现在的课题

### 分析步骤
1. **目的论**："你通过'过去的创伤'达到了什么目的？是否可以把现在的不幸归咎于过去，从而避免'自己做出改变'的责任？是否可以获得'我是受害者'的特别地位？"
2. **赋予意义**："过去的经历本身是客观事实，但你赋予它什么意义是主观选择。同样的经历，有人看作创伤，有人看作成长的历练。你选择了哪种解释？为什么？"
3. **活在当下**："过去已经不存在了。你现在纠结的'过去'，其实是你现在脑海中的记忆。你是在活在'此时此刻'，还是活在'过去的幻影'中？"
4. **人生最大的谎言**："纠结过去、关注未来，而忽略此时此刻——这是不是人生最大的谎言？"

### 行动建议
- 阿德勒的话："任何经历本身并不是成功或者失败的原因。我们并非因为自身经历中的刺激——所谓的心理创伤——而痛苦，事实上我们会从经历中发现符合自己目的的因素。"
- 问自己："如果没有这个'过去的创伤'，我现在会采取什么不同的行动？"——然后现在就去做
- 不是"原谅"过去的伤害者（原谅是纵向关系的居高临下），而是"课题分离"——对方如何对待你是对方的课题，你如何过好现在是你的课题
- 把强烈的聚光灯对准"此时此刻"，认真过好现在能做的每一件小事
- 阿德勒说："起决定作用的既不是昨天也不是明天，而是'此时此刻'。"

## 场景七：选择焦虑/人生迷茫

### 典型表现
- "我不知道自己想要什么，人生没有方向"
- "我害怕选错，所以迟迟不敢做决定"
- "我觉得现在的工作/生活不是我想要的，但又不知道该怎么办"
- "人生的意义到底是什么？"

### 核心概念映射
- 人生是一连串的刹那：人生不是线，是点的连续，不存在"目的地"
- 潜在性人生 vs 现实性人生：不要把人生看作"为了到达终点的过程"
- 甘于平凡的勇气：接受普通不等于无能
- 人生的意义由自己决定：不存在普遍性的人生意义
- 他者贡献：人生的意义在"对他人有用"的贡献感中体现

### 分析步骤
1. **人生是刹那**："你是否把人生看作一条'线'（从过去到未来的故事）？如果人生是点的连续，那么'目的地'还重要吗？"
2. **潜在性 vs 现实性**："你是在过'潜在性的人生'（为了某个目标而活，现在只是准备阶段），还是'现实性的人生'（当下做了当下即完成，过程本身就是结果）？"
3. **甘于平凡**："你是否在追求'特别'（特别优秀或特别差劲）？接受'普通'对你来说意味着什么？普通等于无能吗？"
4. **人生意义**："你是否在等待别人告诉你人生的意义？阿德勒说'并不存在普遍性的人生意义'，意义是你自己赋予的。"

### 行动建议
- 不要把人生看作登山（只有到达山顶才有意义），而要看作跳舞（每一个瞬间都有意义）
- 问："今天就能做到的事情是什么？"——然后认真去做
- 阿德勒说："人生是连续的刹那，根本不存在过去和未来。你是想要通过关注过去或未来为自己寻找免罪符。"
- 培养"甘于平凡的勇气"——普通并不等于无能，我们根本没必要特意炫耀自己的优越性
- 人生的意义在"他者贡献"中寻找：当你感受到"我对他人有用"时，人生的意义自然就会浮现
- 阿德勒的学生奥斯卡·克里斯汀说："今天听了我的话的人，从此刻起就能够获得幸福。但是，做不到这一点的人也将永远无法获得幸福。"

## 场景八：社交恐惧/回避人际关系

### 典型表现
- "我害怕和陌生人说话"
- "我在人群中感到很不自在"
- "我没有朋友，感到很孤独"
- "我不想出门，不想见人"

### 核心概念映射
- 目的论：你通过"社交恐惧"达到了什么目的？——避免在人际关系中受伤
- 一切烦恼源于人际关系：但幸福也源于人际关系
- 课题分离：别人如何看待你是别人的课题
- 人生三大课题：交友课题是必须面对的
- 他者信赖：建立关系需要无条件信赖的勇气

### 分析步骤
1. **目的论**："你通过'社交恐惧/回避'达到了什么目的？是否可以避免'在人际关系中可能受伤'的风险？是否可以获得'我是因为社交恐惧才没有朋友'的借口，而不是面对'即使努力也可能交不到朋友'的现实？"
2. **人生谎言**："你是否在编造'人生谎言'来逃避交友课题？比如'因为我性格内向所以交不到朋友'——这是外部因果律。"
3. **课题分离**："别人如何看待你、是否愿意和你做朋友，这是谁的课题？你是否在为别人的课题而焦虑？"
4. **他者信赖**："建立深厚关系需要无条件信赖的勇气。你是否因为害怕被背叛而选择了怀疑？怀疑的目光能找到'证据'吗？（答案是：总能找到）"

### 行动建议
- 阿德勒说："要想消除烦恼，只有一个人在宇宙中生存。"但那种事情根本无法做到。所以人际关系是无法回避的。
- 从最小的一步开始：主动对一个人说"谢谢"，或者主动参与一次小范围的社交
- 把"别人会怎么看我"替换为"我能为别人做什么"——从对自己的执著转向对他人的关心
- 认识到："在意你长相的，只有你自己。"别人其实没有你想象的那么关注你
- 阿德勒说："必须有人开始。即使其他人不合作，那也跟你没关系。我的意见就是这样：应该由你来开始。不必去考虑他人是否合作。"

## 通用分析流程

无论哪种场景，都可以按照以下流程进行阿德勒式分析：

### 第一步：目的论追问
- "你通过维持这个状态/情绪/想法，达到了什么目的？"
- "如果这个目的不存在了，你会采取什么不同的行动？"
- "你是在'不能改变'，还是在'不想改变'？"

### 第二步：课题分离
- "这件事的结果最终由谁承担？"
- "哪些是你的课题？哪些是别人的课题？"
- "你是否在干涉别人的课题？或者让别人干涉了你的课题？"

### 第三步：共同体感觉检查
- "你是把他人看作'敌人'还是'伙伴'？"
- "你是在和'他人'比较，还是和'理想的自己'比较？"
- "你能否感受到'我对他人有用'的贡献感？"
- "你的关系是纵向的（上下/优劣）还是横向的（虽然不同但是平等）？"

### 第四步：自我接纳→他者信赖→他者贡献
- 自我接纳："你能接受'做不到的自己'吗？你分清了'能改变的'和'不能改变的'吗？"
- 他者信赖："你是在选择'信赖'还是'怀疑'？你能接受'被背叛是对方的课题'吗？"
- 他者贡献："你能感受到'我对他人有用'吗？这种贡献感需要他人的认可吗？"

### 第五步：活在当下
- "你现在能做的、今天就能做到的事情是什么？"
- "你是在活在'此时此刻'，还是活在'过去的幻影'或'未来的想象'中？"
- "你是否把此时此刻贬低成了'准备阶段'或'忍耐阶段'？"
